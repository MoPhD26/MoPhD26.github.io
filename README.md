# mophd26.github.io

Personal portfolio site for Mogahid Hussein, Ph.D., GISP. Plain HTML, CSS, and JavaScript with no build step, served by GitHub Pages.

Live at https://mophd26.github.io

## Structure

* `index.html` holds all page content
* `assets/style.css` holds the styles
* `assets/site.js` runs the project filter and the figure viewer
* `assets/img/` holds the dissertation figures

## Adding a project

Copy one `<article class="card">` block inside the `cards` section of `index.html`, update the text and links, and set `data-tags` to match a filter button.
